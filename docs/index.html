Micro Parser Combinators (mpc-rs)

A lightweight, zero-dependency Parser Combinator library for Rust, ported from Daniel Holden's C library mpc. Build composable, backtracking recursive-descent parsers using pure safe Rust.

1. Overview & Quick Start

When to Use mpc-rs

  • Build a new programming language
  • Parse a new or existing data format
  • Parse existing programming languages
  • Embed a domain-specific language (DSL)
  • Implement complex structured text processing

Core Features

  • Type-Generic: Works with arbitrary Rust types via Box<dyn Any>
  • Predictive Recursive Descent: Composable parsing with backtracking
  • Zero External Dependencies: Single library crate in src/lib.rs
  • Position & Error Reporting: Line, column, and expected tokens in MpcErr
  • Memory Safe: Pure safe Rust leveraging ownership

Installation

[dependencies]
mpc = { path = "../mpc-rs" }  # Adjust path as needed

Quick Start: Mathematical Expression Parser

use mpc::*;

fn main() {
    let number = mpc_digits();
    let plus = mpc_char('+');

    let expr = mpc_or(vec![
        mpc_and(vec![number.clone(), plus.clone(), number.clone()], |_, xs| {
            let a: i32 = xs[0].downcast_ref::<String>().unwrap().parse().unwrap();
            let b: i32 = xs[2].downcast_ref::<String>().unwrap().parse().unwrap();
            Box::new(a + b)
        }),
        number,
    ]);

    match mpc_parse("calc", "1+2", &expr) {
        MpcResult::Ok(val) => println!("Result: {}", val.downcast_ref::<i32>().unwrap()),
        MpcResult::Err(err) => err.print(),
    }
}

Error Handling Pattern

match mpc_parse("input", "invalid", &parser) {
    MpcResult::Ok(result) => { /* Process result */ }
    MpcResult::Err(err) => {
        println!(
            "Parse error at line {}, column {}: {}",
            err.state.row + 1,
            err.state.col + 1,
            err.failure
        );
        println!("Expected: {}", err.expected.join(", "));
    }
}

4.4 State Invariants & Resolution Status

Implemented Invariants

  • UTF-8 Cursor Safety: advance() increments byte offset by c.len_utf8() while maintaining logical pos, row, and col.
  • Backtracking Snapshots: String, Or, And, Count, SepBy, and SepBy1 restore (input.pos, input.state) on failure.
  • Zero-Width Loop Guard: Many and Many1 break when input.pos == before.
  • Peek-Before-Advance & Anchors: Satisfy peeks first; NoneOf fails at EOF; Anchor evaluates f(prev, next).

Sprint 6 Completed Capabilities

  • Recursive AST Assembly: MpcAst::add_child, add_tag, Tag/Root, and mpcf_fold_ast build hierarchical syntax trees.
  • Error Formatting: Display for MpcErr, MpcErr::print(), and mpc_parse() output file, line, column, expected, and received.

Rust TDD Unit Test Suite (src/lib.rs — 21 Tests)

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn satisfy_failure_does_not_advance_input() {
        let parser = mpc_satisfy(|c| c.is_ascii_digit());
        let mut input = MpcInput::new("test", "abc");
        assert!(matches!(parser.parse(&mut input), MpcResult::Err(_)));
        assert_eq!(input.pos, 0);
    }

    #[test]
    fn string_partial_match_backtracks() {
        let parser = mpc_string("hello");
        let mut input = MpcInput::new("test", "hel");
        assert!(matches!(parser.parse(&mut input), MpcResult::Err(_)));
        assert_eq!(input.pos, 0);
        assert_eq!(input.remaining(), "hel");
    }

    #[test]
    fn or_backtracks_after_partial_branch_failure() {
        let parser = mpc_or(vec![mpc_string("abc"), mpc_string("abd")]);
        match mpc_parse("test", "abd", &parser) {
            MpcResult::Ok(val) => assert_eq!(val.downcast_ref::<String>().map(String::as_str), Some("abd")),
            MpcResult::Err(err) => panic!("expected match, got: {}", err.failure),
        }
    }

    #[test]
    fn many_stops_on_zero_width_parser() {
        let parser = mpc_many(mpc_pass(), mpcf_strfold);
        match mpc_parse("test", "abc", &parser) {
            MpcResult::Ok(val) => assert_eq!(val.downcast_ref::<String>().map(String::as_str), Some("")),
            MpcResult::Err(err) => panic!("unexpected error: {}", err.failure),
        }
    }

    #[test]
    fn sepby_backtracks_trailing_separator() {
        let parser = mpc_sepby(mpc_digits(), mpc_char(','), mpcf_strfold);
        let mut input = MpcInput::new("test", "12,34,");
        match parser.parse(&mut input) {
            MpcResult::Ok(val) => {
                assert_eq!(val.downcast_ref::<String>().map(String::as_str), Some("1234"));
                assert_eq!(input.remaining(), ",");
            }
            MpcResult::Err(err) => panic!("unexpected error: {}", err.failure),
        }
    }
}
